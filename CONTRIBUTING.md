# Contributing

## Branches

Create a branch named:

```text
feature/<service>-<topic>
```

Open pull requests into `develop`.

## Commit messages

Use Conventional Commits, for example:

```text
feat(commits): add commit message request
```

## Pull request checklist

- [ ] The project builds.
- [ ] Tests pass.
- [ ] No secrets or `.env` files are included.
- [ ] Only my assigned service and Angular feature were changed.
- [ ] The PR description explains what the change does.
